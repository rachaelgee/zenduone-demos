# ZenduONE interactive demos

Static site: one self-contained HTML file per demo. Deployed with Vercel.

- /shuttle — School & shuttle guided prototype
- /waste — Waste guided prototype
- /airport — Airport ground operations guided prototype
- /driver-safety — Driver calling, safety & maintenance guided prototype
- /live-map — Live Map overview guided prototype (fleet manager)
- /waste-simulation — Waste live simulation (presenter)

## Sales tools
- /deck/school-shuttle — personalisable ZenBUS & Shuttle seller deck (PDF, PowerPoint, Google Slides, Present). Libraries are self-hosted in /vendor.
